# 08 — Listing Launch (Day 0)

## PURPOSE
Launch cleanly, on every relevant channel, at the same moment — and start the vacancy clock precisely, so every later diagnostic (`14_FUNNEL_DIAGNOSTICS.md`, `15_VACANCY_ESCALATION.md`) has an accurate Day 0. Serves: **Vacancy→Tenant**.

## WHEN THIS SOP STARTS
Immediately after `07_MARKETING_PREPARATION.md` assets are approved.

## RESPONSIBLE PERSON
Leasing Lead.

## ESTIMATED TIME
30–45 minutes.

## REQUIRED INPUTS
- Approved photos, copy, floor plan
- Final launch rent (from `04_RENT_PRICING.md`, owner-approved)
- Owner sign-off if required by the onboarding agreement

  Day 0 = this date. Every checkpoint in `15_VACANCY_ESCALATION.md` counts from here.

## COMMON MISTAKES
- Launching on some channels today and others "later this week" — this fragments the vacancy clock and muddies which channel is actually working (`14_FUNNEL_DIAGNOSTICS.md` needs a clean Day 0 across all channels).
- Forgetting to record the launch rent/date, which breaks `19_CAMPAIGN_CLOSEOUT.md`'s "original asking rent vs. final rent" tracking later.
- Publishing without owner sign-off when the agreement requires it.

## ESCALATION CONDITIONS
- If a channel rejects or flags the listing (e.g., platform moderation) → resolve within 24 hours, don't let one blocked channel silently reduce total reach without anyone noticing.

## QUALITY CONTROL
- Every launched listing has: a recorded channel list, a recorded launch date/rent/incentive, and a started vacancy clock.

## OUTPUT / DELIVERABLE
A live listing on every relevant channel, with launch date, launch rent, incentive, and all listing URLs recorded in the property record.
