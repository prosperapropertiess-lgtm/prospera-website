# 26 — Checklist Library

Every checklist referenced across this operating system, compiled for fast reference without flipping between files. The Master Checklist (the single-page version of the entire pipeline) lives in `00_MASTER_TENANT_PLACEMENT_WORKFLOW.md` — this file holds the detailed, stage-specific checklists it summarizes.

---

## Property Acceptance Checklist (01)
- [ ] Pull Discovery Call notes + AI verdict
- [ ] Score 12 leaseability factors → Green/Yellow/Red
- [ ] Confirm capacity
- [ ] Match band to action (proceed / conditional / decline)
- [ ] Log decision + reasoning
- [ ] Send decline/waitlist email within 24h if applicable

## Capacity Checklist (02)
- [ ] Count active placement vacancies
- [ ] Count new assignments this month
- [ ] Determine state: AVAILABLE / NEAR CAPACITY / FULL CAPACITY
- [ ] Apply to any pending acceptance decision
- [ ] If exception requested, run full Exception Approval checklist

## Expectation-Setting Checklist (03)
- [ ] Explain pipeline, not event
- [ ] Set pricing expectations
- [ ] Set timeline expectations
- [ ] Set screening expectations
- [ ] Confirm communication cadence
- [ ] Confirm escalation path
- [ ] Log confirmation

## Rent Pricing — 8 Steps (04)
- [ ] Step 1: Direct comparables
- [ ] Step 2: Same building/complex
- [ ] Step 3: Same neighbourhood
- [ ] Step 4: Expand geography, preserve similarity
- [ ] Step 5: Relax one variable
- [ ] Step 6: Substitute properties
- [ ] Step 7: Active competition
- [ ] Step 8: Adjust for meaningful differences
- [ ] Present 3 price positions + confidence level + review date

## Lead Management Checklist (09)
- [ ] New inquiry logged
- [ ] First contact within target window
- [ ] Qualification complete
- [ ] Showing booked
- [ ] No-response sequence (24h / 72h / 7-day) if silent
- [ ] Post-showing outcome logged
- [ ] Lost-lead reason logged
- [ ] Price-change reactivation run when applicable
- [ ] Every record has STATUS + LAST ACTION + NEXT ACTION + DATE

## Showing Checklists (10)
- [ ] Pre-showing: access confirmed, property presentable, arrive early
- [ ] Confirmation / 24h reminder / 2h reminder sent
- [ ] Arrival: verify identity, fact sheet ready
- [ ] Run showing script
- [ ] No-show handling if applicable
- [ ] Outcome captured same-day: INTERESTED / MAYBE / NOT INTERESTED
- [ ] Objection reason logged for MAYBE/NOT INTERESTED
- [ ] Follow-up sent matching outcome

## Quality Control — 12 Non-Negotiables (21)
See full list in `21_QUALITY_CONTROL.md`. Summary: no ignored inquiry, no lead without next action, no showing without outcome, no owner without scheduled update, no unsupported price recommendation, no applicant left waiting, no property accepted without capacity check, no vacancy sitting undiagnosed, no discriminatory screening, no unresolved BLOCKER at launch, no unauthorized lease deviation, no skipped handoff item.
